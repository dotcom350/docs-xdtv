System Requirements

Minimum specifications for running StreamCore.

Operating System

Supported Linux Distributions

  • Ubuntu 20.04 LTS, 22.04 LTS, 24.04 LTS (Recommended)
  • Debian 11 (Bullseye), 12 (Bookworm), 13 (Trixie)
  • CentOS 8 Stream, 9 Stream
  • Rocky Linux 8, 9
  • AlmaLinux 8, 9
Note: Ubuntu 22.04 LTS is the recommended distribution for production deployments.

Hardware Requirements

Minimum Specifications

  • CPU: 2 cores (4+ recommended for production)
  • RAM: 4 GB minimum (8+ GB recommended)
  • Storage: 20 GB SSD (100+ GB for media storage)
  • Network: 1 Gbps (static IP recommended)

Software Dependencies

For Docker Installation

  • Docker Engine 24.0+ with Docker Compose v2.20+

For Manual Installation

  • Node.js v20.x LTS or higher
  • Rust 1.70+ (via rustup)
  • Build tools: gcc, make, pkg-config, libssl-dev

Network Ports

Required Ports

  • 80 - HTTP (redirects to HTTPS)
  • 443 - HTTPS (frontend + API)
  • 3000 - Backend API (internal)
  • 5000 - Frontend (internal)
Firewall: Ensure ports 80 and 443 are open for external access.

Manual Installation

Complete step-by-step guide for Ubuntu/Debian servers.

Important: This guide assumes you have root access to a fresh Ubuntu 20.04+ or Debian 11+ server.
This manual guide matches the auto-installer.
  • Backend runs on 3000, frontend runs on 5000
  • Requires Node.js v20+ and Rust (via rustup)
  • Builds backend (cargo build --release) and frontend (npm ci + npm run build)
  • Creates iptv-backend and streamcore-frontend systemd services

01 Upload Project Files

CREATE USER (RECOMMENDED)
sudo adduser --disabled-password --gecos "" streamcore sudo mkdir -p /home/streamcore sudo chown -R streamcore:streamcore /home/streamcore
CREATE DIRECTORY
sudo mkdir -p /home/streamcore cd /home/streamcore
VERIFY FILES
ls -la /home/streamcore ls -la /home/streamcore/backend /home/streamcore/frontend

02 Install System Dependencies

INSTALL DEPENDENCIES
sudo apt-get update -y sudo apt-get install -y curl ca-certificates gnupg openssl build-essential pkg-config libssl-dev libsqlite3-dev
FIREWALL (OPTIONAL)
# If you use UFW sudo ufw allow 22/tcp sudo ufw allow 80/tcp sudo ufw allow 443/tcp sudo ufw status

03 Install Node.js v20

INSTALL NODE.JS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get update -y sudo apt-get install -y nodejs node --version && npm --version

04 Install Rust & Cargo

INSTALL RUST
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y source $HOME/.cargo/env rustc --version && cargo --version

05 Configure Backend

CONFIGURE BACKEND .ENV
cd /home/streamcore/backend cp .env.example .env nano .env
GENERATE JWT SECRET
openssl rand -hex 32
Key variables to configure: SERVER_ADDRESS, PUBLIC_BASE_URL, CORS_ALLOWED_ORIGINS, JWT_SECRET, ADMIN_DEFAULT_PASSWORD
BACKEND .env (EXAMPLE)
# Database DATABASE_URL=sqlite:./iptv.db # Server Configuration SERVER_ADDRESS=0.0.0.0:3000 PUBLIC_BASE_URL=https://api.yourdomain.com # CORS (comma-separated allowed origins) CORS_ALLOWED_ORIGINS=https://yourdomain.com,https://www.yourdomain.com # Security (CHANGE THESE!) JWT_SECRET=your_generated_jwt_secret_min_32_chars ADMIN_DEFAULT_PASSWORD=your_secure_admin_password # App Settings SKIP_MIGRATIONS=false DEBUG_MODE=false RUST_LOG=iptv_backend=info,tower_http=warn,sqlx=warn # Backup BACKUP_ENABLED=true BACKUP_DIR=./backups BACKUP_RETENTION_DAYS=30 BACKUP_INTERVAL_HOURS=24 # Stripe Payments (Optional) STRIPE_SECRET_KEY=sk_test_placeholder STRIPE_WEBHOOK_SECRET=whsec_placeholder STRIPE_SUCCESS_URL=https://yourdomain.com/credits/success STRIPE_CANCEL_URL=https://yourdomain.com/credits/cancel STRIPE_CURRENCY=usd

06 Build Backend

BUILD BACKEND
cd /home/streamcore/backend cargo check cargo build --release cp target/release/iptv-backend . chmod +x iptv-backend

07 Configure Frontend

CONFIGURE FRONTEND .ENV.LOCAL
cd /home/streamcore/frontend cp .env.example .env.local nano .env.local
Key variables to configure: NEXT_PUBLIC_API_URL, INTERNAL_API_URL, NEXT_PUBLIC_APP_NAME, STREAMCORE_PROXY_ALLOWED_HOSTS
FRONTEND .env.local (EXAMPLE)
# API Configuration NEXT_PUBLIC_API_URL=https://api.yourdomain.com INTERNAL_API_URL=http://127.0.0.1:3000 # Branding NEXT_PUBLIC_APP_NAME=StreamCore # Debug (set to 'true' for dev) NEXT_PUBLIC_DEBUG_LOGS=false # Proxy Security Settings STREAMCORE_PROXY_ALLOWED_HOSTS=* STREAMCORE_PROXY_REQUIRE_AUTH=false STREAMCORE_PROXY_ALLOW_PRIVATE=true

08 Build Frontend

BUILD FRONTEND
cd /home/streamcore/frontend # Recommended (reproducible install with package-lock.json) npm ci # Optional (if you are installing an older release): keep current majors, patch minimums # npm install react@^19.1.2 react-dom@^19.1.2 next@^15.5.7 --no-fund --no-audit npm run build

09 Create Systemd Services

CREATE BACKEND SERVICE
sudo nano /etc/systemd/system/iptv-backend.service
/etc/systemd/system/iptv-backend.service
[Unit] Description=StreamCore Backend API After=network.target [Service] Type=simple User=streamcore Group=streamcore WorkingDirectory=/home/streamcore/backend EnvironmentFile=/home/streamcore/backend/.env ExecStart=/home/streamcore/backend/iptv-backend Restart=always RestartSec=5 [Install] WantedBy=multi-user.target
CREATE FRONTEND SERVICE
sudo nano /etc/systemd/system/streamcore-frontend.service
/etc/systemd/system/streamcore-frontend.service
[Unit] Description=StreamCore Frontend (Next.js) After=network.target [Service] Type=simple User=streamcore Group=streamcore WorkingDirectory=/home/streamcore/frontend EnvironmentFile=/home/streamcore/frontend/.env.local Environment=NODE_ENV=production ExecStart=/usr/bin/npm run start Restart=always RestartSec=5 [Install] WantedBy=multi-user.target
Note: If you did not create the streamcore user, change User= and Group= to the account that owns /home/streamcore (or use root).

10 Enable & Start Services

ENABLE & START
sudo systemctl daemon-reload sudo systemctl enable iptv-backend streamcore-frontend sudo systemctl start iptv-backend streamcore-frontend

11 Verify Installation

CHECK STATUS
sudo systemctl status iptv-backend sudo systemctl status streamcore-frontend
HEALTH CHECK
curl -fsS http://127.0.0.1:3000/api/health
FRONTEND CHECK
curl -I http://127.0.0.1:5000

Useful Commands

LOGS & RESTART
# View live logs sudo journalctl -u iptv-backend -f sudo journalctl -u streamcore-frontend -f # Restart services sudo systemctl restart iptv-backend sudo systemctl restart streamcore-frontend
Next Step: Configure your reverse proxy (Nginx/Apache) to point your domain to localhost:3000 (backend) and localhost:5000 (frontend).

12 Reverse Proxy (Optional, Recommended)

Recommended setup: Serve the frontend on https://yourdomain.com and the backend API on https://api.yourdomain.com.
INSTALL NGINX
sudo apt-get update -y sudo apt-get install -y nginx
CREATE CONFIG FILE
sudo nano /etc/nginx/sites-available/streamcore
/etc/nginx/sites-available/streamcore
# Frontend: yourdomain.com -> localhost:5000 server { listen 80; server_name yourdomain.com; location / { proxy_pass http://127.0.0.1:5000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } } # Backend API: api.yourdomain.com -> localhost:3000 server { listen 80; server_name api.yourdomain.com; location / { proxy_pass http://127.0.0.1:3000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } }
ENABLE & RELOAD
sudo ln -sf /etc/nginx/sites-available/streamcore /etc/nginx/sites-enabled/streamcore sudo nginx -t sudo systemctl reload nginx
HTTPS: Add DNS records for your domain(s) and issue TLS certificates (e.g., Certbot) before using this in production.

Android App Configuration

Configure the Android app to connect to your backend and customize branding.

Prerequisites: You need Android Studio installed to build the app. The Android app source code is located in Apps/android_app/.

1 Open Project in Android Studio

2 Configure Backend URL & App Name

The app uses local.properties to configure the backend URL and app branding. Copy the template and edit:

Terminal (in android_app folder)
cp local.properties.template local.properties
local.properties
# Android SDK (auto-configured by Android Studio) # sdk.dir=/path/to/your/android/sdk # =========================================== # BRANDING CONFIGURATION # =========================================== # App name displayed throughout the application branding.name=YourAppName # =========================================== # BACKEND URL CONFIGURATION # =========================================== # Set your backend server URL (without /api suffix) # Examples: # Development (emulator): http://10.0.2.2:3000 # Production: https://api.yourdomain.com # Local network: http://192.168.1.100:3000 backend.url=https://api.yourdomain.com
Important: For emulator testing, use http://10.0.2.2:3000 (maps to host machine's localhost). For production, use your HTTPS backend URL.

🔧 Generated Build Config Fields

These values are automatically generated from local.properties:

  • BuildConfig.BRANDING_NAME → From branding.name
  • BuildConfig.API_BASE_URL → backend.url + "/api/"
  • BuildConfig.STREAM_BASE_URL → backend.url + "/stream/"
  • R.string.branding_name → For XML resource usage

3 Customize App Icon (Launcher)

Replace the app icon by modifying files in the res/ directory:

📁 Icon File Locations

File Path Description
ic_launcher_foreground.xml res/drawable/ Vector foreground icon
ic_launcher_background.xml res/drawable/ Background color/gradient
ic_launcher.png res/mipmap-*/ PNG icons (multiple sizes)
ic_launcher.xml res/mipmap-anydpi-v26/ Adaptive icon definition
Tip: Use Android Studio's Image Asset Studio (Right-click on res → New → Image Asset) to generate all required icon sizes automatically from a single source image.

4 Customize Theme Colors

Modify the app's color scheme by editing the theme files:

🎨 Key Color Locations

  • Icon foreground: res/drawable/ic_launcher_foreground.xml → android:fillColor
  • Compose Theme: app/src/main/java/.../ui/theme/Color.kt
  • Compose Theme: app/src/main/java/.../ui/theme/Theme.kt

5 Change Package Name (Optional)

To publish under your own package name (for Play Store):

app/build.gradle (defaultConfig section)
defaultConfig { applicationId "com.yourcompany.yourapp" minSdk 24 targetSdk 35 versionCode 1 versionName "1.0.0" // ... }
Refactoring: In Android Studio, right-click on the package com.iptv.android in the Project view → Refactor → Rename. This will update all references throughout the codebase.

6 Build the APK

📦 Build Options

Debug Build: Menu → Build → Build Bundle(s) / APK(s) → Build APK(s)

Release Build: Menu → Build → Generate Signed Bundle / APK

Output location: app/build/outputs/apk/

Command Line Build (Debug)
./gradlew assembleDebug
Command Line Build (Release)
./gradlew assembleRelease
Done! Your customized Android app is ready. Install the APK on your Android device or publish to the Play Store.
